# Barber Manager

Applicazione gestionale per barbiere, realizzata con Streamlit, SQLite e SQLAlchemy.

## Avvio

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Struttura

- `app.py`: entry point
- `database.py`: configurazione database (placeholder)
- `models/`: modelli SQLAlchemy
- `services/`: logica applicativa (stub)
- `pages/`: schermate multi-pagina
- `tests/`: test
